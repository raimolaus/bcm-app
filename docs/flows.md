# Peamised töövood

## 1) Kriisirežiimi aktiveerimine
Home → “Activate crisis” → vali stsenaarium → Scenario Detail → Save → Incident tekib

## 2) Kübertriage (Incident Metrics)
Scenario Detail → täida Incident Metrics → Save → Incident Log uuendub

## 3) Incident’i haldus
Incident Log → Incident Detail → timeline / checklist / teavitused → export / sulgemine

## 4) ÕPPUS režiim
ÕPPUS toggle ON → uued incidentid märgitakse `isExercise=true`
Filtrid ja sildid peavad seda kajastama igal pool.

## 5) System Status
AUTO arvutus → vajadusel MANUAL override (koos põhjendusega)
