# BCM App — Business Continuity Management

Brauseripõhine **Business Continuity Management (BCM)** rakendus  
intsidentide haldamiseks ja õppuste läbiviimiseks.

Rakendus on:
- **eestikeelne**
- **offline-first**
- **backend’ita**
- **LocalStorage’ile toetuv**
- mõeldud kasutamiseks ka **kriisiolukorras**

> Rakendus on algselt loodud HHLA TK Estonia AS-i sisemiseks kasutuseks.  
> Keele- ja arhitektuurivalikud on tehtud teadlikult sellest kontekstist lähtudes.

---

## 🚦 Kiire kokkuvõte

- Ei ole backend’i
- Ei ole kasutajakontosid
- Ei ole rollimudelit
- Ei ole väliseid sõltuvusi
- Kõik töötab **HTML / CSS / JavaScript** abil brauseris

Kui otsid keerukat enterprise-süsteemi → see ei ole see.  
Kui otsid **lihtsat ja töökindlat kriisihaldustööriista** → oled õiges kohas.
